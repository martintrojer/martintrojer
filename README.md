I build terminal tools to sharpen my workflow, and keep tinkering with a Wayland compositor until it works exactly the way I want. Clojure and Scala in a former life.

- 🖥️ [vtmux](https://github.com/martintrojer/vtmux): Drop-in tmux replacement. Modern stack. Better rendering. Live upgrades.
- 🪟 [swayward-wm](https://github.com/swayward-wm): an i3/sway-compatible
 Wayland compositor (and screen locker) on smithay, plus [sway-ipc-oracle](https://github.com/swayward-wm/sway-ipc-oracle) conformance tests
- 🤖 [mu-crew](https://github.com/mu-crew): A persistent crew of pi agents across all my machines
- 📝 Notes: [mdroots](https://github.com/martintrojer/mdroots) · [ramble](https://github.com/martintrojer/ramble) · [debrief](https://github.com/martintrojer/debrief) · [carddown](https://github.com/martintrojer/carddown) · [vecgrep](https://github.com/martintrojer/vecgrep)
